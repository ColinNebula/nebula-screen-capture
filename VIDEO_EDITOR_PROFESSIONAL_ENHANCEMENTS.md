## 🆕 What's New

### 1. 🟢 **Chroma Key (Green Screen)**
- **Location**: Effects Tab → Professional Effects section
- **Features**:
  - Custom color picker for any chroma key color (green, blue, or custom)
  - Adjustable **Similarity** slider (0-100%) for fine-tuning key range
  - **Smoothness** control for edge refinement
  - **Spill Suppression** to remove color bleeding
- **Use Case**: Remove green/blue screen backgrounds for professional compositing
- **How to Use**:
  1. Open Effects tab in Properties Panel
  2. Enable "Chroma Key (Green Screen)"
  3. Click color picker to select your background color
  4. Adjust Similarity, Smoothness, and Spill Suppression sliders
  5. Preview changes in real-time

### 2. 🎯 **Video Stabilization**
- **Location**: Effects Tab → Professional Effects section
- **Features**:
  - **Strength** slider (0-100%) for stabilization intensity
  - **Smoothing** slider (0-100%) for motion smoothness
  - Professional-grade shake reduction
- **Use Case**: Fix shaky handheld footage or drone videos
- **Pro Tip**: Higher values provide more stabilization but may crop the video slightly

### 3. 📊 **Color Grading Curves Panel**
- **Location**: Filters Tab → Professional Color Grading section
- **Features**:
  - Professional RGB curves visualization
  - Grid overlay with reference lines
  - Diagonal reference for linear color mapping
  - Dedicated curves UI (similar to Photoshop/Lightroom)
- **Status**: Visual panel ready, full curve editing with draggable control points coming soon!
- **Current Alternative**: Use the extensive color correction sliders for now

### 4. 🎵 **Audio Waveform Visualization**
- **Location**: Automatically visible on audio tracks in timeline
- **Features**:
  - Real-time waveform rendering in sequencer timeline
  - Visual representation of audio amplitude
  - Makes it easier to sync audio with video clips
- **How to Use**: Simply add audio clips to audio tracks - waveforms appear automatically!

### 5. ⌨️ **Keyboard Shortcuts Panel**
- **Location**: Click "Shortcuts" button in header OR press `?` key
- **Features**:
  - Comprehensive keyboard shortcut reference
  - Organized by category (Playback, Timeline, Editor, Pro Tips)
  - Beautiful modal design with color-coded sections
  - Shows NEW professional features
- **Shortcuts**:
  - **Space**: Play/Pause
  - **←/→**: Previous/Next Frame
  - **Shift + ←/→**: Jump 1 second back/forward
  - **Ctrl/Cmd + +/-**: Zoom timeline in/out
  - **Ctrl/Cmd + 0**: Reset zoom
  - **?**: Toggle keyboard shortcuts panel
  - **Esc**: Close editor or shortcuts panel

## 💡 Pro Tips

1. **Chroma Key**: Start with Similarity at 40% and adjust from there. Use Smoothness to refine edges.

2. **Stabilization**: Try Strength at 50% first. Increase if shake persists.

3. **Keyboard Shortcuts**: Press `?` to quickly reference all shortcuts without leaving your workflow.

4. **Audio Sync**: Use waveform visualization to align audio peaks with video events.

5. **Color Grading**: Use presets first, then fine-tune with individual sliders.

6. **Timeline Navigation**: Use `Shift + ←/→` for quick 1-second jumps when finding exact moments.

7. **Frame-Perfect Edits**: Use `←/→` to move frame-by-frame for precise trim points.

8. **Clip Splitting**: Double-click any clip to split it at the current playhead position.

9. **Auto-Save**: Your work is automatically saved every 2 seconds - never lose progress!

10. **Magnetic Snapping**: Enable in Sequencer Options to automatically align clips.

## 🎯 Professional Workflow Example

### Creating a Professional Video:

1. **Import Media**
   - Click "Import" in Media Bin
   - Add videos, images, and audio files

2. **Arrange on Timeline**
   - Drag clips from Media Bin to tracks
   - Use magnetic snapping for perfect alignment
   - Double-click to split where needed

3. **Apply Color Grading**
   - Select a preset (e.g., "Cinematic")
   - Fine-tune with Temperature, Tint, Exposure
   - Add Clarity for extra punch

4. **Add Effects**
   - Enable Chroma Key if needed
   - Add Stabilization for shaky footage
   - Apply Vignette or other creative effects

5. **Configure Transitions**
   - Select clip in timeline
   - Adjust Fade In/Out in Properties Panel
   - Choose transition type

6. **Add Text Overlays**
   - Click "Text" tab
   - Add text layer
   - Position and style as desired

7. **Fine-Tune Audio**
   - Use waveforms to sync with video
   - Adjust volume and normalization
   - Set playback speed if needed

8. **Export**
   - Click "Export ▼" button
   - Choose quality preset (e.g., YouTube)
   - Select format (WebM recommended)
   - Click export button
