# 🚀 Quick Start - Professional Video Editor

## ✨ What's New - 5 Professional Features

### 1. 🟢 Chroma Key (Green Screen)
**Location**: Effects Tab → Professional Effects  
**Use**: Remove green/blue backgrounds  
**Quick Setup**:
```
1. Enable "Chroma Key (Green Screen)"
2. Click color picker → select background color
3. Adjust Similarity: 40% (start here)
4. Fine-tune Smoothness & Spill Suppression
```

### 2. 🎯 Video Stabilization
**Location**: Effects Tab → Professional Effects  
**Use**: Fix shaky footage  
**Quick Setup**:
```
1. Enable "Video Stabilization"
2. Set Strength: 50% (recommended)
3. Set Smoothing: 50%
4. Increase if shake persists
```

### 3. 📊 Color Curves Panel
**Location**: Filters Tab → Professional Color Grading  
**Use**: Professional color grading  
**Quick Access**:
```
1. Open Filters Tab
2. Scroll to bottom
3. Click "Open Color Curves Panel"
```
*Note: Full curve editing coming soon - use color sliders for now*

### 4. 🎵 Audio Waveforms
**Location**: Automatic in timeline  
**Use**: Visual audio editing  
**How it Works**:
```
Add any audio clip to timeline → waveforms show automatically!
Perfect for syncing audio with video
```

### 5. ⌨️ Keyboard Shortcuts
**Access**: Press `?` key OR click "Shortcuts" button  
**Essential Shortcuts**:
```
Space          → Play/Pause
←/→            → Frame-by-frame
Shift + ←/→    → Jump 1 second
Ctrl + +/-     → Zoom timeline
?              → Show shortcuts
Esc            → Close
```

## 🎬 Professional Workflow in 5 Minutes

### Step 1: Import (30 seconds)
```
1. Click "Import" in Media Bin
2. Select videos, images, audio
3. Wait for thumbnails to generate
```

### Step 2: Arrange (1 minute)
```
1. Drag clips from Media Bin to timeline
2. Enable "Magnetic Snapping" for perfect alignment
3. Double-click clips to split at playhead
4. Drag to reposition
```

### Step 3: Color Grade (1 minute)
```
1. Click "Filters" tab
2. Choose a preset:
   • Cinematic (film look)
   • Vivid (enhanced colors)
   • Vintage (old film)
3. Fine-tune with sliders
```

### Step 4: Add Effects (1 minute)
```
1. Click "Effects" tab
2. Try these popular effects:
   • Vignette: 20-30%
   • Sharpen: 10-20%
   • Chroma Key: if green screen
   • Stabilization: if shaky
```

### Step 5: Transitions (30 seconds)
```
1. Select clip in timeline
2. Scroll to "Clip Transitions" in Properties
3. Set Fade In: 0.5s
4. Set Fade Out: 0.5s
```

### Step 6: Export (1 minute)
```
1. Click "Export ▼"
2. Choose preset:
   • YouTube (1080p 60fps)
   • Instagram (1080x1080)
   • High (1080p 30fps)
3. Click export
4. Wait for rendering
```

## 🎯 Pro Tips for Common Tasks

### Green Screen Removal
```
✅ DO:
• Use bright, evenly-lit green/blue screen
• Start with Similarity at 40%
• Increase Smoothness for better edges
• Enable Spill Suppression

❌ DON'T:
• Use wrinkled or unevenly lit backgrounds
• Set Similarity too high (causes artifacts)
• Forget to adjust Smoothness
```

### Video Stabilization
```
✅ DO:
• Start with 50% strength
• Use 50% smoothing
• Preview before exporting
• Expect slight crop at high values

❌ DON'T:
• Set strength to 100% immediately
• Use on intentionally shaky shots
• Forget to check crop amount
```

### Color Grading
```
✅ DO:
• Start with a preset
• Make small adjustments (+/- 10-20)
• Use Temperature for mood:
  - Warm (+30 to +50) for sunset/cozy
  - Cool (-30 to -50) for tech/cold
• Add Clarity for extra sharpness

❌ DON'T:
• Max out all sliders (looks unnatural)
• Apply too many effects at once
• Forget to reset if it looks bad
```

### Audio Syncing
```
✅ DO:
• Look for audio peaks in waveform
• Match peaks with visual events
• Use frame-by-frame (←/→) for precision
• Enable magnetic snapping

❌ DON'T:
• Rely on visual timing alone
• Forget to check sync at export
```

## ❓ Troubleshooting

### "Effects not visible in preview"
```
Solution: Some effects only render on export
• Try: Export a short clip to test
• Filters/transitions always preview
```

### "Chroma Key not working well"
```
Solutions:
1. Check lighting (evenly lit background)
2. Lower Similarity (start at 30-40%)
3. Increase Smoothness
4. Try different key color (sample from video)
```

### "Stabilization crops video too much"
```
Solutions:
1. Lower Strength (try 30-40%)
2. Lower Smoothing
3. Accept slight crop for smooth footage
```

### "Auto-save not working"
```
Check:
1. Browser allows localStorage
2. Not in Incognito/Private mode
3. Check browser console for errors
```

### "Export taking too long"
```
Tips:
1. Use "Medium" or "Low" preset for testing
2. Trim video to needed section only
3. Reduce resolution if acceptable
4. Close other applications
```

## 🎓 Advanced Techniques

### Professional Color Grading
```
1. Start with preset (e.g., Cinematic)
2. Adjust Temperature: +15 to +25
3. Lower Highlights: -10 to -20
4. Increase Shadows: +5 to +15
5. Add Clarity: +15 to +25
6. Fine-tune Saturation: -5 to +10
Result: Professional film look!
```

### Multi-Layer Compositing
```
1. Video 1 (Background): Bottom track
2. Video 2 (Subject): Middle track
3. Enable Chroma Key on Video 2
4. Add text overlay on top track
5. Set transitions on all clips
Result: Professional composite!
```

### Audio Synchronization
```
1. Add video to Video Track 1
2. Add audio to Audio Track 1
3. Enable Audio Waveforms
4. Find audio peak (e.g., clap)
5. Align peak with visual clap
6. Use ←/→ for frame-perfect sync
Result: Perfect sync!
```
