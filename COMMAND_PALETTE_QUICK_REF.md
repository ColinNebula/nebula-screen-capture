# Command Palette - Quick Reference Card

## 🚀 Opening Command Palette
| Action | Shortcut |
|--------|----------|
| Open/Close Command Palette | `Ctrl+K` or `Ctrl+P` |

## 📋 Essential Commands

### 🎬 Recording
| Command | Shortcut |
|---------|----------|
| Start/Stop Recording | `Ctrl+R` |
| Pause/Resume | `Space` |
| Take Screenshot | `Ctrl+Shift+S` |
| Toggle Webcam | `Ctrl+W` |
| Toggle Microphone | `Ctrl+M` |

### 📁 File Operations
| Command | Shortcut |
|---------|----------|
| Open File Manager | `Ctrl+O` |
| Search Files | `Ctrl+F` |
| Refresh Files | `F5` |

### ✂️ Editing
| Command | Shortcut |
|---------|----------|
| Open Editor | `Ctrl+E` |
| Trim Video | `Ctrl+T` |
| Apply Filter | `Ctrl+Shift+F` |
| Add Text | `Ctrl+Shift+T` |
| Export Video | `Ctrl+Shift+E` |

### 📦 Batch Operations
| Command | Shortcut |
|---------|----------|
| Toggle Batch Mode | `Ctrl+B` |
| Select All | `Ctrl+A` |
| Batch Download | `Ctrl+Shift+D` |
| Batch Delete | `Ctrl+Shift+Delete` |

### 🧭 Navigation
| Command | Shortcut |
|---------|----------|
| Open Settings | `Ctrl+,` |
| Open Help | `F1` |
| Toggle Theme | `Ctrl+Shift+L` |

## ⌨️ Navigation Keys
| Key | Action |
|-----|--------|
| `↑` / `↓` | Navigate items |
| `Enter` | Execute command |
| `Tab` | Switch category |
| `Esc` | Close palette |
| Type | Filter/Search |

## 💡 Pro Tips

1. **Fuzzy Search**: Type partial names - "rec" finds "Start Recording"
2. **File Access**: Type file names to open them instantly
3. **Category Filter**: Use Tab to cycle through command categories
4. **Batch Workflow**: Enable batch mode → select files → execute operation
5. **Learn Shortcuts**: Displayed shortcuts help you work faster

## 🎯 Common Workflows

### Quick Record & Edit
```
Ctrl+K → "start" → Enter (start recording)
Ctrl+S (stop)
Ctrl+K → "editor" → Enter (open editor)
Ctrl+Shift+E (export)
```

### Batch Download
```
Ctrl+K → "batch" → Enter (enable batch mode)
Select files with checkboxes
Ctrl+Shift+D (download all)
```

### Fast Navigation
```
Ctrl+K → Type command name → Enter
```

**Remember**: `Ctrl+K` is your friend! Open it anytime to access any feature instantly.
